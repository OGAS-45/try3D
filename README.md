- 网页展示和算法实验是不同入口，运行前分别检查依赖和资源路径。
- `.blend`、模型文件、截图和视频属于成果资料，整理时保留原始版本。
- 本次只补充内容导航，尚未重新验证各 Demo 的运行环境。
- 对外使用模型、图片或视频前，核对各素材的来源和使用范围；仓库存在文件不等于已授予统一使用许可。
